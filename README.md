# 🍅 Kalkulator Przetworów

Polska aplikacja do przeliczania przepisów na przetwory. Oblicza ilość składników i potrzebnych słoików.

## 🌟 Funkcje

- **Przeliczanie przepisów** - dostosuj ilość składników do różnych słoików
- **Import przepisów** - z plików TXT, DOCX, PDF
- **Eksport wyników** - do TXT, DOCX, PDF z polskimi znakami
- **Kalkulator słoików** - oblicza ile słoików potrzebujesz
- **Historia obliczeń** - zapisuje ostatnie przeliczenia

## 🚀 Instalacja

### Wymagania
- Python 3.6+
- Biblioteki: `python-docx`, `reportlab`, `pypdf2`
